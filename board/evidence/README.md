| --- | --- |
| `20261025-historical-classic-rs485.json` | 历史1M/485单轮通过，不能覆盖后续失败 |

新增 v0.3 记录：`20261025-fd5m-30min.json` 保留30分钟压测的收齐帧数与严格失败；`20261025-rs485-rate.json` 保留1.5M持续通过及更高速率失败。

验收策略：逐帧/字节一致且所有接收、发送、总线、勘误错误增量为零。收齐数据但有恢复重试也保留失败，不降低标准制造绿灯。发送端485物理自回显另计，对端接收才算跨口成功。

原始记录保存在设备与操作者本地工作区，摘要提供原文件SHA256；原始日志可能包含设备网络身份，不随公共仓库发布。公开JSON按白名单移除设备IP、hostname、boot_id、网络与远控身份/密码，仅保留测试数据、参数、时间和摘要。未记录线长、端接电阻实测、双绞/接地和示波器波形；不宣称长线、EMC、生产或物理最高速率合格。

代码来源和勘误解释：`driver/rockchip_canfd-rx.c`的勘误6处理增加`tx_extended_as_standard_errors`与`tx_errors`后重试；当前统计一致，说明进入该恢复路径。驱动处理了已识别异常，不等于消除了硬件勘误，或排除了其他物理条件问题。

`20261025-system-logos.json`：关于页面实屏截图、全局图标哈希和启动标志只读审查；Plymouth/Linux logo保持禁用，U-Boot未刷写、未做物理开机画面验收。
