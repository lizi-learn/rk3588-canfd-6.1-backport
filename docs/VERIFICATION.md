# 验证范围与外部验收

`evidence/verification-summary.json` 从保存的实际测试记录按字段选取，去除了设备地址、主机名、会话标识与原始日志。
这是已有结果的可公开摘要，不是这次发布时重新执行的硬件测试。

## 实际完成

重启前后各一轮；每轮两路分别测试经典 CAN 名义 1M、FD 名义1M / 数据1M、2M、5M。
8组 × 10000帧 × 2轮 = 160000 个应用发送帧。每组硬件内部 RX 和 TX 完成回显各10000帧，分别计数并逐帧核对。

- 接收 flags=0 对应控制器内部回环 RX，flags=2052 对应发送完成回显。
- 正式通过组无新增 bus_error、bus_off、error_warning、error_passive，TX/RX 错误计数为0。
- 标准/扩展 ID；经典长度0-8；FD长度0-8、12、16、20、24、32、48、64。
- FD 设置 BRS/FDF；未宣称每个长度和每种 ID 类型的所有笛卡尔组合均覆盖。
- 内核 RX 统计可能包含硬件内部 RX 与本地 echo，不可把2倍包数当作外部接收量。
- 重启后两路绑定到新驱动；最终为正常 FD 1M/5M、回环关闭。

## 尚未完成

没有外部接线，因此收发器、接插件、线缆、对端 ACK 或业务设备的物理收发不计通过。
3M 内部失败单独记录，不能用5M成功覆盖。没有测实际物理最高速率或持续有效吞吐。
没有提交上游合入，不代表原厂认证。

## 后续外部测试条件

1. 两路独立总线或FD分析仪，核对 CANH、CANL、公共参考地、终端、电源及目标对端支持的格式。
2. 仲裁1M / 数据5M，双向逐帧核对并关闭发送端软件回显；同时确认没有软件网关。
3. 结合真实线长、节点数和终端安排做持续负载，保存错误/丢帧/恢复统计。
4. 在 CANH/CANL 测位宽、差分电压、反射和采样裕量；线速设定值不替代波形量测。

自研底板图示的 CAN-A 为 J46/J47 并联，CAN-B 为 J50/J51 并联；每路1=CANH、2=CANL、3=GND、4=24V。
只在同版本实板逐脚核对后使用，跨两路测试连接1↔1、2↔2、3↔3，4脚不接。
每路图示120Ω，测试前按实物与拓扑确认。公共软件仓库未附原理图，也不代替实装检查。

## 复测要求

记录目标内核/头文件、编译器、模块哈希、设备树、时钟及对端设置。
内核或板卡变更后重新构建与验证，不复制本机结论给其他硬件。
